NOVA Digital Menu
==================
فایل اصلی: index.html

برای تغییر آیتم‌ها و قیمت‌ها:
1) فایل index.html را با VS Code یا Notepad++ باز کنید.
2) بخش‌های مربوط به منو را پیدا کنید.
3) بعد از تغییر، فایل را دوباره در GitHub آپلود/Commit کنید.

رنگ‌بندی: قرمز تیره + مشکی + طلایی
طراحی: موبایل‌محور، RTL، با المان‌های قهوه و کافه
